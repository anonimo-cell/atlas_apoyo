# Atlas de Apoyo

Página de inicio del proyecto **Atlas de Apoyo**: catálogos accesibles de productos de apoyo.
Desde aquí se accede a cada atlas, por ejemplo el [Atlas de apoyo Parkinson](https://anonimo-cell.github.io/atlas_apoyo_parkinson/).

Web publicada: https://anonimo-cell.github.io/atlas_apoyo/

## Estructura

```
index.html                    Página principal
0_css/estilos.css             Estilos
javascript/accesibilidad.js   Tamaño de texto y alto contraste
svg/                          Logos del proyecto
img/logos/                    Logos de colaboradores
.github/workflows/static.yml  Publicación automática en GitHub Pages
```

## Ver en local

Abre `index.html` en el navegador.

## Publicación

Cada `push` a la rama `main` publica la web automáticamente en GitHub Pages
(en el repositorio: **Settings → Pages → Source: GitHub Actions**).
